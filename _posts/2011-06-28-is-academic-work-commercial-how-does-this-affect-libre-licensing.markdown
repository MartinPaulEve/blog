  content: ! 'This is a good question or thought to ponder. As a doctorate student,
    I am wondering if/how this type of publishing will impact higher education now
    and forward. There are many academics who support open publishing and a shared
    doctrine of learning. The question does arise in traditional academia - how does
    this relate to the requirements for tenure? I like the thought shared by Dr. Kathleen
    Rowe, in a recent article : 
    "it isn’t just ethically incumbent on us as scholars to publish in open-access
    venues, but in fact to create more open-access publications, and more systems
    for their support. These systems might include new public or foundation-based
    granting agency programs specifically designed to support open-access publications." http://www.plannedobsolescence.net/on-open-access-publishing/Does
    this then make these CC published works commercial? I would say that you are probably
    correct in using the CC-BY licence. The Budapest Open Access Initiative published
    a Guide to Open Access Publishing and Scholarly Societies http://www.soros.org/openaccess/html/open_access_publishing_and_scholarly_societies.htm created
    a helpful guide that indicated on pp. 20-21 that CC-BY is the best license to
    use for academic scholars. Here is another open access data base that was developed
    from the same group that you might find interesting: http://www.doaj.org/'

<p>I've been engaged recently in <a href="https://twitter.com/#!/jonhickman/status/85697414178144257">a discussion on Twitter</a> as to the appropriateness of <a class="zem_slink" title="Creative Commons" rel="wikipedia" href="http://en.wikipedia.org/wiki/Creative_Commons">Creative Commons licensing</a> for <a class="zem_slink" title="Open access journal" rel="wikipedia" href="http://en.wikipedia.org/wiki/Open_access_journal">Open Access journals</a> wishing to remove permission barriers, ie. become "libre". It seems there is a real problem as to how to define academic work.</p>
<p><img class="alignnone size-full wp-image-1240" style="width: 750px;" title="Academic Books" src="https://www.martineve.com/wp-content/uploads/2011/06/academic_books-e1309268508498.jpg" alt="Academic Books" /></p>
<p>My original instinct was to go with a CC-BY-NC license as this would allow redistribution, use etc. in a context that was non-commercial. This would mean that authors could publish openly at this stage and, if a commercial publisher later wanted to republish (in an anthology for instance), they'd have to negotiate with the author. The problem, though, is that academic work cannot straightforwardly be defined as non-commercial. If a publication comes out with a commercial publisher that makes reference to another piece of work, this could close down citations.</p>
<p>In short, is what we do on a daily basis (reading, writing, researching, publishing) commercial? If we are paid a salary, does that make it commercial? If I publish with an commercial publisher, that almost certainly makes it so. Some of these considerations have already been touched upon by <a href="http://www.jisc.ac.uk/publications/briefingpapers/2009/bpcreativecommons.aspx">JISC in their paper</a> on this topic.</p>
<p>This is, I would guess, the logic that <a class="zem_slink" title="PLoS" rel="homepage" href="http://www.plos.org">PLoS</a> went through when deciding <a href="http://www.plos.org/journals/license.php">their license</a> and I am beginning to come round to that opinion myself, to cite Beckett. While the conversation is still ongoing, it looks as though there is no license that adequately defines non-commercial as "reprinting in entirety, in a commercial publication" and, as a result, CC-BY is the way to go.</p>
